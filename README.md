InsightsbyJMR PowerShell

##https://www.jmrinsights.co.in/

A collection of PowerShell scripts I've built, adapted, and picked up along the way to make day-to-day IT work a little easier.

Most of these started with a simple problem: I found myself doing the same thing more than once and thought, “there has to be an easier way.”

Some scripts are built from scratch, while others are based on ideas, references, or existing solutions that I've adapted to fit a specific use case. Wherever applicable, I'll try to give credit to the original source.

What's inside?

You'll find scripts for things like:

Automating repetitive tasks
Troubleshooting common issues
Collecting system information
Simplifying day-to-day IT operations
Fixing problems that probably shouldn't require doing the same steps manually every time

I'll keep adding things here whenever I build, improve, or come across something useful enough to keep.

Before you run anything

These scripts are shared because they've been useful to me, but please don't blindly run anything just because it's on GitHub — even if I wrote it. 😄

Take a look at the script, understand what it does, and test it in a safe environment before using it on production systems.

Some scripts may require:

Administrator privileges
Specific PowerShell versions or modules
Changes based on your environment

Always check the individual script or its documentation before running it.

Contributions & feedback

If you find something useful, spot an issue, or have an idea to improve a script, feel free to open an issue or contribute.

And if one of these scripts saves you a few clicks, a few minutes, or saves you from doing the same annoying task again — then it has done its job. 🙂
